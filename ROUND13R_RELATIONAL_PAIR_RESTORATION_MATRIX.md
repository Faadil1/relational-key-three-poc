# ROUND 13R — RELATIONAL PAIR RESTORATION

## Canonical invariant

**THE RELATIONAL PAIR REMAINS THE PRODUCT.**

Every RELATIONAL KEY Cultural Edition must preserve the original POC architecture:

1. **Card A — Credential / Member / Claim**
2. **Card B — Counterpart / Destination / Context / Rule**
3. **A visible gap** before registration
4. **A relationship event** that happens between the two objects
5. **Continuation or resistance** as the outcome
6. **Explanation on demand** after the relationship outcome

Universal interaction law:

`ENCOUNTER → APPROACH → COMPARE → REGISTER / RESIST → CONNECT → CONTINUE → EXPLAIN`

The cultural edition may radically change the visual language, material, physics and connection mechanism, but may not collapse the pair into one card.

## Gate for all existing variants

A variant cannot be promoted if any answer below is NO:

- Are two distinct card objects visible before resolution?
- Does each card carry a different relational role?
- Is there a visible gap between them?
- Is the cultural mechanism expressed in that gap, not only inside one card?
- Does matching registration change the relationship between both cards?
- Does no-match leave both objects valid but separate/resistant?
- Is the connection secondary at rest and legible during resolution?
- Does the result still read as RELATIONAL KEY when labels are hidden?

## Project rule

**NO NEW CULTURAL VARIANT UNTIL ALL CURRENT VARIANTS PASS THE RELATIONAL PAIR GATE.**

The current research, real-source assets, visual worlds and interaction discoveries are preserved. Round 13R changes architecture, not cultural evidence.
