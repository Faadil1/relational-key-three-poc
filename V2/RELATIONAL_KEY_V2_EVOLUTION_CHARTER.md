## 4. Archive Intelligence Layer

V2 upgrades the existing protocol:

`ARCHIVE CORPUS → MECHANISM EXTRACTION → CULTURAL CLAIM → RELATIONAL TRANSLATION → DISTANCE TEST`

into an interaction-first pipeline:

`ARCHIVE CORPUS → BEHAVIOR / MATERIAL / SPATIAL MECHANISM → RELATIONAL LAW → 3D INTERACTION → MATCHING / OTHER → MEMORABLE CONSEQUENCE`

Archives are not moodboards.

A source may be classified as:

- `DIRECT_VISUAL_REFERENCE` — reproduction is supported by rights/provenance;
- `MECHANISM_ONLY` — may shape behavior/geometry but not be copied visually;
- `MATERIAL_REFERENCE` — informs surface, construction or physical response;
- `SPATIAL_REFERENCE` — informs relative position, pivot, alignment or movement;
- `TEMPORAL_REFERENCE` — informs sequence, rhythm, duration or event ordering;
- `CONTEXT_ONLY` — supports truth copy but not the visual mechanism;
- `RESTRICTED_OR_REVIEW_REQUIRED` — cultural, community, rights or sensitivity review required.

### Archive Specificity Test

## 6. Runtime architecture laws

`raw-bits-to-react` is used through TRACE Web Runtime Assurance as conceptual doctrine. Runtime evidence and current official platform/framework guidance remain authoritative.

V2 runtime principles:

1. **Do not render 24 live WebGL canvases on the Atlas.**
   - Atlas cards use lightweight previews/posters.
   - Instantiate the family canvas only when the family is active.
2. Lazy-load family scene code and heavy assets.
3. Keep deterministic product state outside continuous render loops.
4. Prefer event-driven / demand rendering when continuous animation is not part of the mechanism.
5. Dispose geometries, materials, textures, audio nodes, listeners and observers on unmount.
6. No React state update per frame for values that belong in refs/shaders/animation systems.
7. Profile before optimizing. A rerender is not a defect unless evidence shows material wasted work, state error or user-visible degradation.
8. Separate lab evidence, React Profiler evidence, browser performance evidence and source hypothesis.
9. Mobile/constrained-device behavior is a first-class target, not a post-build fallback.
10. New hosted previews are budgeted evidence actions.

## 7. Accessibility architecture laws

Every 3D interaction must have:

- semantic DOM controls outside or alongside canvas;
- keyboard/touch path equivalent to pointer manipulation;
- programmatic outcome announcement;
- reduced-motion behavior;
- meaningful non-visual explanation of the relational state;
- no essential truth encoded only by color, camera motion, sound or depth;
- a usable low-motion/static state when motion is not essential to understanding.

Canvas is presentation. Product truth remains accessible outside the canvas.
