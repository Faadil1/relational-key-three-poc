# C. OMBAK BALI

## Chosen V2 mechanism target

V2.1 is scoped to the **paired tuning / beating relation** documented for Balinese gamelan, using gong-kebyar / paired-metallophone evidence as the primary conceptual scope.

`LOWER PAIRED SOURCE + HIGHER PAIRED SOURCE → FREQUENCY DIFFERENCE → AMPLITUDE BEATING / OMBAK`

The pilot is not a generic “Balinese music visualizer” and does not claim one universal Bali-wide frequency standard.
