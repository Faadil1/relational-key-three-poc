# 2 — FUNICULAR · VALPARAÍSO

Slug: `funicular-valparaiso`

## Refreshed authoritative basis

Consejo de Monumentos Nacionales de Chile — Ascensor Concepción:

- https://www.monumentos.gob.cl/monumentos/monumentos-historicos/ascensor-concepcion

Current official record confirms:

- Valparaíso / Cerro Concepción;
- creation in 1883;
- Concepción was the first Valparaíso ascensor/funicular built in 1883;
- the system arose to connect the port/plain with the steep hills.

Official Chilean heritage technical documentation:

- https://www.monumentos.gob.cl/sites/default/files/articles-45668_doc_pdf.pdf

The documentation distinguishes Polanco from the other systems and describes the Valparaíso funiculars as two wooden or metal cars moving together in opposite directions.

UNESCO World Heritage Centre contextual corroboration:

- https://whc.unesco.org/en/list/959

UNESCO identifies Valparaíso's funicular elevator infrastructure as part of the historic quarter's industrial-age heritage.

## V1 inheritance

Frozen V1 already proved the strongest form of this relation:

- both cars visible simultaneously;
- direct manipulation of either member;
- exact inverse positional response in the other;
- no pair button;
- no success/failure endpoint;
- reversible continuous relation.

## V2 pair contract

**Card A — FUNICULAR CAR A / TRACK**

Owns Car A and one bounded inclined track field.

**Relation — SHARED FUNICULAR / INVERSE POSITION**

Owns the restrained cable/counterposed positional relation only.

**Card B — FUNICULAR CAR B / TRACK**

Owns Car B and the complementary track field.

Canonical law:

`CAR A POSITION ↔ SHARED FUNICULAR / INVERSE POSITION ↔ CAR B POSITION`

Formal interaction invariant:

`B = 1 - A`

and when B is directly manipulated the same relation solves A.

## Memorable moment

The evaluator drags either car and the other answers immediately with equal/opposite positional motion. Neither member is a follower decoration; agency can start on either side.

## Semantics

This family should not be forced into a false MATCHING/OTHER binary.

Valid states include:

- `A LOW / B HIGH`
- `OPPOSED MOTION`
- `CROSSING`
- `A HIGH / B LOW`
- `SWAP START`

All are states of the same valid relation.

## Truth boundary

- isolates the documented two-car counterbalancing/opposite-motion subsystem;
- not a traction, braking, load, speed or energy engineering simulator;
- do not imply the cars alone supply all motive power;
- no perpetual-motion framing.

## Asset / rights decision

`PROCEDURAL_GEOMETRY_ONLY_UNLESS_EXPLICIT_MEDIA_LICENSE_IS_LATER_VERIFIED`

Current official heritage pages are sufficient to ground mechanism and form, but this gate does not authorize copying their photography.

## Runtime target

LOW–MEDIUM.

Use linked deterministic transforms, no unrestricted physics simulation. Preserve simultaneous two-card geometry on mobile.

## Collision verdict

No current six-candidate memorable moment uses continuous symmetric inverse agency.

Nearest mechanical candidate is Coupler, but:

- Coupler → contact / lock / shared load;
- Funicular → already-linked continuous equal/opposite motion with no success state.

**PASS.**

# 3 — MUSIC BOX · SAINTE-CROIX

Slug: `music-box-sainte-croix`

## Refreshed authoritative basis

Swiss federal Museum of Music Automatons / Seewen:

- https://www.musikautomaten.ch/en/collection-en
- https://www.musikautomaten.ch/dam/en/sd-web/rIutgSBDvxDt/F%C3%BChrung%20MAGIC%20PIANO%20-%20SELBSTSPIELENDE%20WUNDER%20Besucherfassung%20EN%2010-24.pdf

The museum currently documents:

- Swiss cylinder/disc music boxes as a major collection focus;
- mechanical-music heritage rooted in the Jura arc;
- pin-studded cylinders as storage media;
- a cylinder transmitting stored information through set pins;
- pins plucking tuned teeth in sequence;
- the cylinder + comb principle in traditional Swiss music boxes.

Exact object anchor:

Smithsonian National Museum of American History — Paillard & Cie. Cylinder Music Box:

- https://americanhistory.si.edu/collections/object/nmah_605759

Current object record confirms:

- Charles Paillard & Cie.;
- St. Croix / Sainte-Croix, Switzerland;
- 1841;
- cylinder music box;
- four tunes;
- one-piece comb with 51 teeth;
- key-wound metal spring activation.

Companion Paillard object:

- https://americanhistory.si.edu/collections/object/nmah_605758

It is dated about 1838–1842 and documents a one-piece 50-tooth comb with key-wound spring activation.

## V1 inheritance

Frozen V1 correctly isolated the decoding subsystem rather than a complete cabinet:

`PINNED CYLINDER ≠ TUNED COMB → ENGAGE → ROTATE → PIN CONTACT → TOOTH PLUCK → ORDERED NOTES`

The prior candidate also proved that direct manual rotation can make the causal relation legible while explicitly labeling that manual input as an editorial substitution for historical spring drive.

## V2 pair contract

**Card A — PINNED CYLINDER / STORED SEQUENCE**

Owns the cylinder, editorial pin map and direct manual rotation.

**Relation — PIN-TO-TOOTH CONTACT / ROTATION**

Owns only deterministic contact events generated by the relation.

**Card B — TUNED COMB / PHYSICAL DECODER**

Owns tooth response and optional synthetic tone evidence.

Canonical law:

`PINNED CYLINDER / STORED GEOMETRY → PIN-TO-TOOTH CONTACT → TUNED COMB RESPONSE → ORDERED SYNTHETIC PHRASE`

## Memorable moment

A visible pin on Card A reaches the relation, a specific tooth on Card B responds, and a short synthetic note may sound. The stored sequence is only revealed through repeated cross-card contacts.

## Alternate-valid semantics

`OTHER CYLINDER` must select another valid editorial pin map and produce another valid phrase. No red failure state.

## Truth boundary

- manual cylinder rotation is editorial input substitution;
- historical spring drive remains visible in explanation;
- simplified pin maps / comb-tooth counts are editorial;
- no claim of authentic Paillard tuning, timbre or historical tune;
- audio is optional evidence, not the product.

## Asset / rights decision

`PROCEDURAL_GEOMETRY_AND_SYNTHETIC_AUDIO_ONLY`

The current Smithsonian Paillard object page states that image re-use has restrictions. This gate therefore authorizes the metadata/mechanism facts as source evidence but **does not authorize copying the Smithsonian images**.

Museum imagery likewise remains reference-only unless an explicit reusable license is verified later.

No sampled historical recording is authorized.

## Runtime target

MEDIUM.

Use deterministic pin-event mapping and bounded Web Audio. No autoplay and no unrestricted physics/contact engine.

## Collision verdict

- Ombak also uses audio/temporal response.

**PASS because consequence differs:**

- Coupler contact → latch / shared load;
- Ombak paired sources → interference / beat envelope;
- Music Box stored pin geometry → discrete physical decode into ordered tooth events.

The center must not become a waveform, piano roll or score hero.
