## Underrepresented relationship territories

The following territories are intentionally broader than a single culture or object.

### R1 — BALANCE / COUNTERWEIGHT
Two unequal members produce stability only through proportional opposition.

Potential digital verbs:
`LOAD → OFFSET → COUNTER → LEVEL → HOLD`

Distinct from:
- tension registration;
- reciprocal cut;
- simple visual symmetry.

### R2 — HINGE / ROTATION / ARTICULATION
Two bounded members change meaning through a pivot, joint or controlled angular relationship.

Potential verbs:
`PIVOT → ALIGN ANGLE → ENGAGE → OPEN/CLOSE`

Distinct from:
- flat registration;
- tessellation fit.

### R3 — FOLD / OVERLAP / LAYER REVEAL
Neither surface alone exposes the full structure; a crease or overlap creates a second readable state.

Potential verbs:
`CREASE → FOLD → OVERLAP → REVEAL → UNFOLD`

Distinct from:
- edible transformation;
- photographic trace.

### R4 — LOAD / STACK / ACCUMULATION
Relationship depends on order, support, pressure or cumulative placement rather than lateral matching.

Potential verbs:
`PLACE → BEAR → STACK → TRANSFER LOAD → STABILIZE`

Distinct from:
- woven interlace;
- material tessellation.

### R5 — LATCH / CLASP / DISCRETE ENGAGEMENT
Two members remain independent until a specific engagement geometry changes the system state.

Potential verbs:
`APPROACH → CATCH → LATCH → HOLD → RELEASE`

Distinct from:
- zellige fit, because the state change must depend on engagement rather than passive adjacency.

### R6 — PROJECTION / SHADOW / OCCLUSION
One bounded member modifies, casts, masks or completes the visual information of the other through light or line-of-sight.

Potential verbs:
`CAST → OCCLUDE → ALIGN → RESOLVE IMAGE`

Distinct from:
- stereoscopic binocular fusion;
- photographic archive trace.

### R7 — TRANSFER / POUR / CONTAINMENT
Relationship is expressed through controlled movement of material, quantity or state from one bounded member into another.

Potential verbs:
`TILT → TRANSFER → RECEIVE → LIMIT → SETTLE`

Distinct from:
- generic transformation;
- service switch logic.

### R8 — EXCHANGE / ROLE REVERSAL
The relation is created by reciprocal transfer of role, token, position or obligation — not by shared-cut inversion.

Potential verbs:
`OFFER → RECEIVE → RETURN → EXCHANGE → REBALANCE`

Distinct from:
- Boulle reciprocal geometry;
- simple matching.

### R9 — CYCLE / SYNCHRONIZATION
Two independent periodic systems create a meaningful state when cycles align, diverge or phase-lock.

Potential verbs:
`CYCLE A + CYCLE B → DRIFT → SYNCHRONIZE → WINDOW`

Distinct from:
- Ombak beat resonance;
- Siku alternating melody.

### R10 — COMPRESSION / EXPANSION / STORED FORCE
A relation stores force and releases it as a legible state change.

Potential verbs:
`PRESS → STORE → THRESHOLD → RELEASE → RETURN`

Distinct from:
- Hika Ahi friction;
- Khipu tension alignment.

### R11 — ENCODE / DECODE / COMPLETION
Two partial information objects form a readable code only through a specific relation.

Potential verbs:
`PART A ≠ PART B → COMBINE → DECODE → READ`

Distinct from:
- visual trace;
- generic registration.

### R12 — CALIBRATE / TUNE / MEASURE
Two independent standards or instruments establish a valid relation through comparison and adjustment.

Potential verbs:
`COMPARE → OFFSET → CALIBRATE → VERIFY`

Distinct from:
- visual alignment for its own sake;
- binary matching.

## Cross-collection anti-duplication tests

A candidate should be rejected or heavily challenged if its law can be reduced to any of these without meaningful loss:

- "move the cards together until they line up";
- "two halves complete one picture";
- "one image reveals another image";
- "two patterns tessellate";
- "two sounds combine";
- "two objects exchange colors but not roles";
- "a culturally specific visual is placed on an existing interaction template".
