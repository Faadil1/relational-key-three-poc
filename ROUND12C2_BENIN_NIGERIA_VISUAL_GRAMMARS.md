# 01 — BENIN / SERVICE REGISTER

## Core cultural mechanism

**SERVICE AS STORYBOARD**

Historic telecom cards repeatedly turned the service itself into the graphic subject: service names, usage concepts, instructions, tariff structures and communication features.

## Visual law

> **THE PATH EXPLAINS ITSELF WHILE IT REGISTERS.**

## Primary geometry

The path is divided into functional clauses.

Example skeleton:

`━━ 01 ━━ 02 ━━╸     ╺━━ 03 ━━ 04 ━━`

At registration:

`━━ 01 ━━ 02 ━━●━━ 03 ━━ 04 ━━`

The numbers do not represent fake historical usage. They represent the current service logic of the prototype.

## Field primitives

- service bands,
- numbered clauses,
- tariff-like horizontal rules,
- compact instruction blocks,
- callout brackets,
- state-change markers,
- one dominant registration switch.

## Junction

### SWITCH REGISTER

Before match:

`╸  )   (  ╺`

After match:

`━━━[●]━━━`

The junction should feel like a service being switched into an active state, not like a transit node.

## Information anatomy

Front hierarchy:

1. edition / service family,
2. service sequence field,
3. interrupted path,
4. junction,
5. member / claim information.

Back hierarchy:

1. compact service explanation,
2. valid-through / ID,
3. fallback verification,
4. optional four-step service legend.

## Microtypography

Use language as functional notation:

`01 CLAIM`
`02 SERVICE`
`03 REGISTER`
`04 CONNECT`

Short labels only.

No decorative prose.

## Motion behavior

`READ → ALIGN → SWITCH → CONTINUE`

During proximity, service clauses may progressively become legible.

At valid match, the switch register closes and the remaining clauses activate in order.

At invalid match, the sequence stops at the switch. Nothing flashes red.

## Black/white signature test

With all names/colors removed, the edition must still be recognizable by:

- segmented service sequence,
- numbered clauses,
- switch-style junction,
- compact instruction anatomy.

## Anti-patterns

- vintage phone illustration,
- rotary handset icon,
- generic African motif,
- copied PTT graphics,
- faux-retro distress,
- decorative tariff tables with fake data.

# 02 — NIGERIA / SIGNAL PORTRAIT

## Core cultural mechanism

**INFRASTRUCTURE AS PORTRAIT**

Historic phonecard families repeatedly elevated telecommunications infrastructure itself: Earth Station imagery, satellite/relay logic, denomination families, launches and test/sample states.

## Visual law

> **THE FIELD REVEALS THE INFRASTRUCTURE CAPABLE OF CARRYING THE RELATIONSHIP.**

## Primary geometry

The credential path approaches a compact infrastructural field rather than a city field.

Before:

`━━━━━━╸        )))   ○   (((`

Registration:

`━━━━━━●━━━━━━`
`      )))○(((`

Continuation exits through the same infrastructural node.

## Field primitives

- radial signal arcs,
- horizon/base line,
- relay node,
- concentric registration rings,
- denomination-like bands,
- calibration ticks,
- TEST / REGISTERED state notation,
- one dominant infrastructure silhouette generated from abstract geometry.

## Junction

### RELAY CORE

The junction is not merely on the line.

It sits inside a larger infrastructural registration field.

Before:

`━━╸       ( ( ○ ) )`

After:

`━━━━━━━( ( ● ) )━━━━━━━`

The orange/red point in later color work would remain the semantic core; the surrounding rings belong to the archive-derived field.

## Information anatomy

Front hierarchy:

1. edition / signal family,
2. infrastructure field,
3. interrupted path entering relay core,
4. registration state,
5. member / claim information.

Back hierarchy:

1. signal relationship explanation,
2. ID / validity,
3. prototype state legend,
4. verification.

## Microtypography

Borrow the discipline of technical/test objects without copying historical marks:

`FIELD 01`
`CLAIM A`
`RELAY READY`
`REGISTERED`

Use serial notation sparingly.

## Motion behavior

`APPROACH → ACQUIRE → ALIGN → RELAY → CONTINUE`

At proximity, the field acquires the credential.

Compatible geometry causes rings/relay marks to align concentrically.

Incompatible geometry creates visible off-axis residual and a small angular recoil.

The mismatch geometry should cause the mismatch motion.

## Black/white signature test

With all names/colors removed, the edition must still be recognizable by:

- radial infrastructure field,
- relay core,
- calibration/test notation,
- path entering and leaving a field rather than crossing a map.

## Anti-patterns

- satellite-dashboard sci-fi,
- glowing radar,
- literal dish illustration as hero,
- copied NITEL branding,
- Nigerian flag palette shortcut,
- nostalgia as the concept.
