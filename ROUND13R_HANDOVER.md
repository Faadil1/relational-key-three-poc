# ROUND 13R — HANDOVER

## Goal
Restore the original RELATIONAL KEY product architecture across every current Cultural Edition before any new variant is explored.

## Frozen invariant
**THE RELATIONAL PAIR REMAINS THE PRODUCT.**

Every edition must keep:
- Card A: Credential / Member / Claim
- Card B: Counterpart / Destination / Context / Rule
- visible gap before resolution
- culturally derived relationship event in the gap
- registered continuation or calm resistance

## Shared restoration prototype
`round13r-pair-restoration.html`

It currently remaps all six existing variants into the same two-card skeleton:
1. City Passage
2. Service Register — Benin
3. Signal Portrait — Nigeria
4. Trace System — Frida / Coyoacán
5. Edible Passage — Toyama / Masu no Sushi
6. Woven Register — Asante / Bonwire

## Variant-specific connection laws
- City: route/corridor crosses the gap.
- Service: missing service step resolves between both cards.
- Signal: relay alignment allows signal propagation across the gap.
- Frida: photographic/trace seam aligns between memory and archive cards.
- Food: pressure register spans the pair, then release/unfold/reveal occurs.
- Textile: woven strips terminate on facing edges, interlace across the gap and join.

## Status of legacy branches
Existing variant branches remain evidence/material studies. They are not canonical final architecture until their implementation is ported to the two-card invariant.

## Required sequence before new categories
1. Validate the shared Round 13R prototype structurally.
2. Port City/Service/Signal to explicit card-pair presentation.
3. Port Frida to two collectible cards rather than card + archive panel.
4. Port Food to two-card edible passage while preserving real-food reveal.
5. Port Textile to two-card woven join while preserving real textile.
6. Browser audit all six.
7. Only then resume category expansion.

## Do not do
- Do not create a seventh cultural variant yet.
- Do not collapse a counterpart into a background field.
- Do not make the connection the dominant visual at rest.
- Do not discard the research/assets/mechanisms already created.
