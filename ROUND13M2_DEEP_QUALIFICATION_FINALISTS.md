# FINALIST A — FRANCE / BOULLE MARQUETRY / PARTIE + CONTREPARTIE

## Verified mechanism

The Met documents the core Boulle process clearly: a thin sheet of tortoiseshell and a thin sheet of metal such as brass are placed together, cut through according to one design, then separated. The resulting pieces can be recombined into reciprocal versions — one with brass in a tortoiseshell ground and the other with tortoiseshell in a brass ground.

The Met also documents paired furniture in which one surface is the exact material reverse of the other, produced without wasting the complementary cut material.

## Native relation test

### Both sides required?
**YES — VERY HIGH.**

The target relation is not simply one material being decorated by another. The shared cut creates two complementary sets. The inverse relationship only exists because both sheets underwent the same cut.

Remove either sheet and the selected `partie ↔ contrepartie` reciprocity disappears.

## Emergent third result

The emergent information is:
**COMPLEMENTARY INVERSION / RECIPROCAL MATERIAL MAP.**

Neither sheet independently contains the knowledge that every positive piece on one side corresponds to a negative receiving field on the other. That reciprocal map is produced by the shared cut.

## Canonical law candidate

# **ONE SHARED CUT PRODUCES TWO COMPLEMENTARY INVERSES.**

Proof:
`SHEET A ≠ SHEET B → STACK → SHARED CUT → SEPARATE → EXCHANGE → PARTIE ↔ CONTREPARTIE`

## Smallest truthful card architecture

- Card A — `PARTIE / DARK GROUND + LIGHT INLAY`
- Card B — `CONTREPARTIE / LIGHT GROUND + DARK INLAY`
- Gap — `SHARED CUT / RECIPROCAL EXCHANGE REGISTER`

Cards should remain reciprocal, not visually identical.

## MATCHING state

`SHARED CUT`

1. two material fields begin distinct;
2. one editorial cut path registers across both;
3. cut fragments separate;
4. reciprocal exchange occurs;
5. each card receives the other material in inverse positions;
6. the center shows that one cut path generated both outcomes;
7. `PARTIE ↔ CONTREPARTIE` registers.

## OTHER state

`OTHER CUT`

- both sheets/material fields remain valid;
- cut paths do not correspond to one shared reciprocal map;
- fragments can remain individually coherent;
- no complete inverse exchange registers;
- no red invalidation.

This is truthful: absence of the selected shared-cut relationship does not make either material invalid.

## Distinctness from existing families

- **not Fès:** Fès = distinct pieces satisfy a material/geometric fit. Boulle = a single shared cut generates reciprocal positive/negative material sets.
- **not Kento:** Kento = sequential print registration / transfer. Boulle = material removal and reciprocal exchange, not impression.
- **not Stereoscopy:** no optical fusion or disparity.
- **not Siku:** no temporal alternation.

# FINALIST B — ITALY / VENICE / RETICELLO

## Verified mechanism

The Met defines reticello as two superimposed layers of glass canes spiralling in different directions. Their overlapping white threads create a network. The museum object used as evidence is public domain.

Corning Museum of Glass describes the process as a double layer of twisted canes, one spiralling clockwise and the other counterclockwise; intersections generate characteristic voids/bubbles in the glass matrix.

## Native relation test

### Both sides required?
**YES — HIGH.**

The selected reticello network depends on the second oppositely spiralling layer. One spiral layer alone remains a valid filigrana layer but does not produce the crossed network.

## Emergent third result

**NETWORK / CROSSING MATRIX.**

Neither layer alone contains the diamond-like crossing structure. It appears through superposition of opposite directions.

## Canonical law candidate

# **OPPOSING SPIRALS PRODUCE A NETWORK.**

Proof:
`CLOCKWISE ≠ COUNTERCLOCKWISE → SUPERIMPOSE → CROSS → NETWORK`

## Smallest truthful card architecture

- Card A — `CLOCKWISE CANE LAYER`
- Card B — `COUNTERCLOCKWISE CANE LAYER`
- Gap — `RETICELLO CROSSING FIELD`

## MATCHING state

`OPPOSING LAYERS`

- two directional cane fields remain distinct;
- cards approach / overlap conceptually;
- crossing intersections appear progressively in the center;
- a network becomes legible only when both directions contribute;
- registered state preserves both directional origins.

## OTHER state

`OTHER LAYER`

Potential truthful option:
- two layers remain valid;
- second layer uses the same directional bias or an offset pattern that does not produce the selected reticello crossing field;
- no target network registers;
- no invalidation.

This requires care: the Other state must not claim that any non-opposing Venetian filigrana relation is historically a failed reticello. It should simply state that the selected reticello network is not registered.

## Distinctness

- not Stereoscopy: visual superposition exists, but the output is a physical/material crossing network, not perceptual fusion or depth;

- not Ombak: no wave interference;
