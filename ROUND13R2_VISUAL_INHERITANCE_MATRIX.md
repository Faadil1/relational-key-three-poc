# ROUND 13R.2 — Visual Inheritance Matrix

The relational pair is now the fixed product architecture. This pass records what each cultural variant is allowed to inherit visually without collapsing back into a single-card experience.

## Shared invariant
**CARD A × CARD B → RELATIONSHIP EVENT → CONTINUATION**

## Variant inheritance

### CITY — Registered City Passage
- Card A: member / local-or-external claim
- Card B: territory / destination rule
- inherited visual world: civic grid / corridor field
- inter-card event: route crosses the unresolved gap
- preserve: territory geometry, restrained blue/coral route language
- forbid: territory becoming a full-screen map that replaces the pair

### SERVICE — Benin Service Register
- Card A: service claim / first part of sequence
- Card B: service context / complementary steps
- inherited visual world: service-as-storyboard
- inter-card event: missing service step resolves between the cards
- preserve: sequence logic, explanatory clarity
- forbid: generic process dashboard / flowchart replacing the objects

### SIGNAL — Nigeria Signal Portrait
- Card A: link claim
- Card B: relay / infrastructure rule
- inherited visual world: infrastructure as portrait / relay core
- inter-card event: signal propagates only after relay alignment
- preserve: signal arcs, relay calibration, restrained infrastructure geometry
- forbid: generic network graph or detached technical diagram

### FRIDA — Trace System
- Card A: memory credential with real portrait trace
- Card B: archive credential with real Coyoacán / Casa Azul trace
- inherited visual world: real photographic archive, ivory/charcoal editorial restraint
- inter-card event: trace seam aligns between the two cards
- preserve: real-source-only rule, photographic presence, subtle connection
- forbid: archive panel becoming a dashboard or replacing Card B as an object

### FOOD — Edible Passage
- Card A: food-memory credential / pressed-wrapped state
- Card B: regional context credential / food reveal context
- inherited visual world: real Masu no Sushi photography, bamboo/wood/food palette
- inter-card event: pressure register spans both cards, then release/reveal occurs within the pair
- preserve: real food first, pressure/release logic, appetizing final state
- forbid: food object replacing the relational pair

### TEXTILE — Woven Register
- Card A: woven credential with interrupted strip
- Card B: weaving context credential with corresponding strip
- inherited visual world: real Asante textile imagery, strip construction
- inter-card event: strips align/interlace across the gap
- preserve: real textile first, strip continuity, no invented motif meaning
- forbid: single decorative Kente card with an internal seam only

## Family-level visual rule
**CULTURAL AESTHETICS MODIFY BOTH CARDS AND THE WAY THEY CONNECT — NEVER THE EXISTENCE OF THE PAIR.**
