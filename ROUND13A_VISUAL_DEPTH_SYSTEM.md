# ROUND 13A — VISUAL DEPTH SYSTEM

Status: IN PROGRESS

## Objective
Push RELATIONAL KEY beyond a clean geometric prototype into a visually distinctive, collectible, manufacturable cultural object system.

The next step is NOT to add more countries. The next step is to deepen the visual language of the proven City / Service / Infrastructure mechanisms.

## Frozen invariants
- REGISTERED CONTINUATION remains the core law.
- Same path must remain interrupted before relationship registration.
- Junction remains the proof event.
- No-match never invalidates the credential.
- Explanation remains on demand.
- Archive → mechanism → translation remains mandatory.
- Cultural specificity may not be reduced to flags, generic motifs, tourist iconography, or a national palette shortcut.

## New visual-depth stack
Every edition may now be composed from six layers.

1. OBJECT SHELL
   - CR80 physical credibility
   - edge, radius, thickness, front/back hierarchy
   - matte/soft-touch or standard printable substrate

2. ARCHIVE FIELD
   - the mechanism-derived field: city fragments, service sequence, infrastructure signal field, etc.
   - must remain recognizable in monochrome

3. RELATIONAL PATH
   - the strongest continuous graphic element
   - interrupted before match, continuous after match
   - may vary in rhythm by edition, never in semantics

4. JUNCTION PROOF
   - the signature registration event
   - may use print registration, matched marks, spot varnish, emboss/deboss, metallic or fluorescent spot ink when manufacturable
   - avoid fake holographic/sci-fi effects

5. PROVENANCE MICRO-LAYER
   - archive reference number / edition number / source family / date range / mechanism label
   - microtype, registration marks, calibration ticks, denomination/sequence cues
   - should reward close inspection without cluttering the hero view

6. DIGITAL RESPONSE
   - proximity, registration, continuation, field response, no-match resistance
   - motion must amplify the physical logic rather than add spectacle

## Visual ambition
The object should work at three distances:

### 5 METERS / THUMBNAIL
Recognizable field silhouette + path + junction.

### ARM'S LENGTH
Edition identity, material contrast, hierarchy, collectible presence.

### MACRO / INSPECTION
Archive-derived microdetails, provenance, print marks, sequence logic, hidden structural clues.

## Three visual-depth directions to prototype

### A — CITY / CARTOGRAPHIC REGISTRATION
For City Passage.
- quiet ivory object
- cobalt field fragments
- layered cartographic microprint
- directional path crossing real-seeming civic notation
- junction behaves like a precise print-registration target
- subtle tactile/spot-varnish possibility at the junction
- no skyline, no decorative transit icons

### B — SERVICE / INSTRUCTIONAL RELIC
For Service Register.
- service bands and numbered steps become the dominant archive layer
- process marks, micro-instructions, denomination/sequence logic
- path moves through functional stages
- junction behaves like a switch / registration seal
- printed step numbers or service codes can become collectible variation logic
- avoid retro pastiche; use archive mechanism, not vintage styling

### C — SIGNAL / CALIBRATED INFRASTRUCTURE
For Signal Portrait.
- radial field, relay alignment and signal arcs
- registration marks and calibration ticks
- possible restrained metallic/technical spot ink on infrastructure lines
- junction behaves like a relay core, not a glowing sci-fi orb
- macro close-up should reveal engineered precision

## Material rule
No material effect may exist only to look premium.
Every finish must correspond to a product meaning.

Examples:
- emboss/deboss = physical proof of junction / registration
- spot varnish = latent field revealed under angle/light
- metallic ink = infrastructure / conductive or relay layer
- fluorescent spot = active relation state / service activation
- translucent window = only if it truly represents incomplete/completed registration and remains manufacturable

## Collection rule
A collection should feel richer as more editions are placed together.
Variation may come from:
- field geometry
- archive rhythm
- sequence density
- microtype/provenance system
- material finish
- accent color
- numbering / denomination family

But one edition must remain identifiable without relying on color.

## Visual anti-patterns
Reject:
- generic premium black/gold
- glossy fintech gradients
- holographic sci-fi
- neon NFC rings
- fake emboss/shadows that cannot be manufactured
- decorative country motifs
- giant portraits pasted onto cards
- tourist landmarks
- archive scans used as wallpaper
- random texture overlays

Create one comparative VISUAL DEPTH BOARD showing City / Service / Signal at three levels:
1. full-card hero

3. provenance / material close-up

The board must answer:
- Does each card feel materially distinct?
- Does the family remain unmistakably RELATIONAL KEY?
- Is the junction still the strongest signature?
- Does archive evidence influence structure rather than decoration?
- Would the physical card be plausible to manufacture?

## Promotion rule
PROMOTE VISUAL DEPTH only if:
- family recognition remains immediate
- archive mechanisms remain legible
- geometry still works in monochrome
- microdetails reward inspection
- premium feeling comes from information + material logic, not effects
- 5-second signature is stronger than before
