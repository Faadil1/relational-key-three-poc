# 2. Source grounding

## Argentina cultural heritage inventory

Argentina's national cultural-heritage inventory documents `Mate` in Entre Ríos and describes a widespread practice in which:
- yerba mate is placed into a vessel;
- hot water is added;
- the beverage is taken through a `bombilla`;
- mate may be consumed individually or shared;
- historical records attribute yerba-mate use to Guaraní people;
- the practice extends broadly beyond the single inventory location.

Source:
https://www.argentina.gob.ar/cultura/manifestaciones-del-patrimonio-cultural-inmaterial/entre-rios/mate

The RELATIONAL KEY family must not claim that this one inventory entry defines the full mate tradition.

## British Museum object taxonomy

The British Museum catalogs `bombilla` objects explicitly under the term:
`mate-strainer`.

Its collections include examples from Argentina, Uruguay, Paraguay, Peru, Chile, Brazil and broader South American contexts.

Source:
https://www.britishmuseum.org/collection/term/x7826

This supports the functional filtering role without requiring RELATIONAL KEY to invent a detailed hydraulic mechanism.

## Smithsonian NMAI object evidence

Smithsonian NMAI documents South American `Mate straw/Bombilla` objects, including an Aymara example from Bolivia.

Source:
https://www.si.edu/object/mate-strawbombilla%3ANMAI_207196

This reinforces the non-exclusive regional framing.

# 5. Interaction contract

## Initial state — SEPARATE

- Mate vessel is already prepared as a particulate infusion field;
- Bombilla is separate;
- no flow is represented;
- both objects are visible.

Label:
`MATE ≠ BOMBILLA · NO SELECTIVE FLOW PATH`

## Insert

Action:
`INSERT BOMBILLA`

Transition:
`SEPARATE → APPROACH → FILTER SUBMERGED`

Pair movement should make the bombilla visibly enter or overlap the mate vessel's liquid/yerba field without erasing Card B.

Insertion creates the functional relation but does NOT automatically create flow.

## Draw — sustained direct input

Preferred primary input after insertion:
# **PRESS / HOLD THE BOMBILLA TO DRAW**

Pointer:
- pointerdown/touchstart on Bombilla starts a restrained represented flow;
- pointerup/cancel stops flow immediately.

Keyboard fallback:
- Space or Enter keydown starts draw;
- keyup stops.

This is preferable to a one-click `DRINK` animation.

No mouth/person is represented.

## Selective passage proof

During DRAW:
- liquid-flow marks move only inside/along the bombilla flow path;
- particulate yerba remains visibly within Card A;
- the filter-end area may show small particles held back;
- liquid level may change very subtly if needed, but no quantitative volume claim is made.

Result language:
`LIQUID PATH ACTIVE · PARTICULATE FIELD REMAINS`

The UI should visually prove separation without showing microscopic filtration accuracy.

## Release / Continue

On release:
- represented flow stops;
- Mate + Bombilla remain inserted/paired;
- user can draw again.

This is a continuous relation:
`DRAW → RELEASE → DRAW → RELEASE`.

There is no final success state.

## Reset

`RESET`:
- stops draw;
- separates Bombilla from Mate;
- restores initial liquid/particle presentation;
- returns to `SEPARATE` state;
- preserves both valid objects.
