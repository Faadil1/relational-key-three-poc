# ROUND 12C.4 — Cross-Cultural Interactive Implementation Plan

## Goal

Turn the cross-cultural board into one interactive RELATIONAL KEY prototype with three archive-derived mechanisms:

- CITY PASSAGE — Gatineau / City Field
- SERVICE REGISTER — Benin / Service Sequence Field
- SIGNAL PORTRAIT — Nigeria / Infrastructure Field

## Product law (frozen)

INTERRUPTED PATH → RELATIONSHIP COMPARE → REGISTRATION JUNCTION → SAME PATH CONTINUES

## Interaction

GRAB → APPROACH → COMPARE → REGISTER / RESIST → CONTINUE / RECOIL → EXPLAIN ON DEMAND

## Controls

- EDITION: CITY / SERVICE / SIGNAL
- CLAIM: MATCHING CLAIM / OTHER CLAIM
- BLIND TEST: removes archive accent differences so geometry can be judged without color
- RESET
- TEST RELATIONSHIP

## Truthfulness

- Gatineau field is a conceptual civic-field encoding, not an operational transit map.
- Benin service sequence is an archive-derived prototype grammar, not an official current telecom service procedure.
- Nigeria signal portrait is an archive-derived infrastructure grammar, not an official NITEL technical diagram.
- Registration profiles and residual are internal prototype encodings.

## Promotion gate

The implementation can be promoted only if:

1. the same drag/register interaction remains understandable in all three editions;
2. city/service/signal feel structurally different before explanatory text;
3. blind mode preserves those differences;
4. no-match semantics remain consistent;
5. the archive mechanism changes the field, not the product law;
6. no edition relies on a logo, flag, national color or decorative stereotype to be recognizable.
