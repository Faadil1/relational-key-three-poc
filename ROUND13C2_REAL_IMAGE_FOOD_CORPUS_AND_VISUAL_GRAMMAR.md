# ROUND 13C.2 — REAL-IMAGE FOOD CORPUS + VISUAL GRAMMAR

## Scope

Pilot category: FOOD MEMORY
Pilot territory: Toyama, Japan
Promoted object: Masu no Sushi / masuzushi
Working RELATIONAL KEY mechanism: EDIBLE PASSAGE

## Why this pilot

This object is stronger than a generic ekiben because the food, circular container, bamboo leaves, compression, regional identity, portability and opening ritual already form a native visual system.

The design does not need to place a photo of food inside an existing card template. The food object itself can become the interaction architecture.

## First-party / high-authority evidence

### JNTO — ekiben as regional food + travel culture
Japan National Tourism Organization describes ekiben as a food culture created by rail travel and regionalized cuisine, with local ingredients and distinctive packaging. JNTO specifically lists Masu no Sushi from Toyama and describes its cedar container, trout over Toyama rice, and bamboo-leaf wrapping.
Source: https://www.japan.travel/en/guide/experience-japans-local-ekiben-culture/

### Minamoto — history of Masu no Sushi
Minamoto documents:
- 1908: railway-station bento business begins at Toyama Station.
- 1912: Masu no Sushi begins sales.
- 1962: the present boxed format emerges and the basic box shape is retained for decades.
- 1963: production evolves from natural vine ties / solid wood toward elastic pressing bands and plywood to preserve pressure while improving transport.
- 1965: package artwork by Kazumasa Nakagawa is introduced.
Source: https://www.minamoto.co.jp/about/history-of-minamoto

Toyama City tourism also presents Minamoto as a century-old ekiben maker and the Masu-no-Sushi Museum as a site where the food culture, craft, tools and making process can be observed.
Sources:
- https://www.toyamashi-kankoukyoukai.jp/en/spot/masunosushimuseum/
- https://www.toyamashi-kankoukyoukai.jp/en/sushinomachitoyama/masu/minamoto-museum/

## Candidate comparison

### A — Touge no Kamameshi / Gunma
Strengths:
- strong earthenware vessel identity
- warm food / thermal story
- born in 1958 as a deliberate challenge to cold standard ekiben
- strong reusable-container history

Weaknesses for first Food Memory pilot:
- vessel risks becoming the hero more than the food
- interaction grammar trends toward HEAT / VESSEL rather than edible reveal

Status: KEEP FOR FUTURE FOOD-VESSEL EDITION

### B — Masu no Sushi / Toyama
Strengths:
- circular compression geometry
- bamboo leaves create radial unfold
- food itself becomes a strong salmon / white rice / green leaf color field
- container, pressure, portability and reveal are one system
- long documented railway history from 1912
- large pool of reusable Commons photography

Status: PROMOTE

## Promoted visual/product law

# EDIBLE PASSAGE

> A regional food memory is compressed into a portable object; a valid relationship releases the structure and reveals the meal.

Canonical sequence:

PRESS → ALIGN → REGISTER → RELEASE → UNFOLD → REVEAL

The RELATIONAL KEY junction is not a separate metal device here.
It is translated into the pressure / opening logic of the food container.

## Native geometry

### Closed state
- circular or near-circular pressed vessel
- crossed / radial restraint logic
- bamboo/leaf edges mostly hidden
- food not fully visible

### Comparison state
- pressure points / alignment marks emerge
- claim and regional memory field compare around the circular structure
- no giant external seam

### Registered state
- restraint resolves
- leaf geometry begins to open
- central food field becomes visible

### Revealed state
- salmon/trout surface + white rice + green bamboo leaf form the main visual composition
- region / provenance becomes secondary micro-information

### Research-only / restricted-use note

`Masunosusi.jpg` documents the recognizable branded package and is licensed CC BY-SA 3.0 / GFDL as a photograph. However, the package itself contains artwork introduced by Minamoto in 1965 and attributed by Minamoto to artist Kazumasa Nakagawa.

For the prototype, do NOT copy or recreate that artwork as our own graphic layer. If a photo containing the package appears, treat the underlying package artwork as a separate rights consideration. Prefer food-only, leaf, container and craft photographs for final visible surfaces.

## Visual grammar

### Primary palette
Do not impose the Frida palette.
Native colors come from the object:
- salmon / trout pink-orange
- rice white
- bamboo-leaf green
- pale wood / cedar
- black / charcoal only for interface restraint

### Typography
Typography must be subordinate to food.
Use small institutional / provenance labels only.
No giant country name.
No faux-Japanese brush font.

### Object hierarchy
1. FOOD SURFACE
2. LEAF / CONTAINER GEOMETRY
3. RELEASE / REGISTRATION EVENT
4. REGION / PROVENANCE
5. UI CONTROLS

### Interaction signature
Idle:
- object mostly closed
- food is hinted, not fully presented

Match:
- pressure/alignment markers resolve
- restraints relax
- leaf field unfolds
- food becomes dominant

No-match:
- restraints do not release
- object remains valid and intact
- no red X / no failure spectacle

### Explanation-on-demand
Drawer can explain:
- Toyama
- 1912 launch by Minamoto
- station-bento history
- bamboo / wood / pressing structure
- photo credits and licenses

Do not claim:
- official partnership with Minamoto
- official railway integration
- official digital food credential system

## Blind distinctiveness test

Hide all labels and country names.
The Food Memory edition should still be identifiable as a different mechanism from:
- City Passage
- Service Register
- Signal Portrait
- Cultural Figure / Trace System

Success condition:
The user sees a pressed food object that opens/reveals itself, not a generic card with a food photo.
