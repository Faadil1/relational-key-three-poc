# ROUND 13C.3 — EDIBLE PASSAGE INTERACTIVE IMPLEMENTATION

## Status
IMPLEMENTED CANDIDATE — browser audit required before promotion.

## Pilot
Toyama / Masu no Sushi

## Product law
**The food object becomes the credential.**

## Interaction law
PRESS → ALIGN → REGISTER → RELEASE → UNFOLD → REVEAL

## Implementation
- Replaces the inherited cross-cultural shell with a food-native composition.
- Uses two states of one food object: sealed/compressed and revealed/unfolded.
- Relationship geometry is translated into the central pressure point rather than an external card-to-card seam.
- Real Masu-zushi photography from Wikimedia Commons is used for the visible meal/material surfaces.
- Bamboo texture is derived from a real CC BY source image rather than generated imagery.
- Claim modes: MATCHING CLAIM / OTHER CLAIM.
- Matching claim runs six-stage reveal and ends in `MEAL MEMORY REVEALED`.
- Other claim recoils calmly, keeps the object sealed, and does not imply that the food object is invalid.
- `WHY THIS WORKS` opens source/provenance explanation on demand.
- Reduced motion supported.
- Progressive haptics are optional and fail safely.

## Truthfulness boundary
Real:
- Toyama regional cuisine context.
- Trout / vinegared rice / bamboo leaf / bentwood / pressure preparation model.
- Referenced photographic sources and licenses.

Conceptual:
- RELATIONAL KEY Food Memory credential.
- Relationship registration claim.
- Pressure-to-registration interface semantics.
- Reveal state as digital interaction.

No official relationship with MAFF, Toyama tourism organizations, Wikimedia photographers, restaurants, rail operators, or ekiben producers is claimed.

## Promotion gate
Do not merge until browser audit confirms:
1. Food is the first visual read.
2. Closed object feels tactile, not diagrammatic.
3. Revealed state feels substantially more vivid than resting state.
4. Central relation remains subordinate until registration.
5. Six-step sequence is understandable but does not dominate the object.
6. Real images load reliably.
7. No-match remains calm and keeps the food object sealed rather than presenting an error state.
8. Mobile layout preserves the food-first hierarchy.
